# Jacquiline Gimena — Portfolio (Beige / Warm Theme)

Plain HTML, CSS and JavaScript. No frameworks, ready for GitHub Pages.

## Files
- `index.html` — all page content
- `style.css` — styling (palette: cream #FAF6F2, beige #DED1BD, gold #B08401, blush #D49E8D, brown #683B2B)
- `script.js` — mobile menu, active nav link, "View Details" toggle, footer year
- `assets/images/` — put your profile photo and project screenshots here

## Still to fill in (shown in gold italics, e.g. `[Your actual role]`)
- IntelliView: role, duration, technologies, status, contribution, project link
- Two extra project cards: name, description, tools, contribution, optional link
- Education: achievements, certifications, training
- Contact: GitHub and LinkedIn URLs (dashed pills near the bottom)

## Adding real things
- Profile photo: replace the `.profile-frame` block in the hero with `<img src="assets/images/profile.jpg" alt="Jacquiline Gimena">` and style it to fit.
- Project link: replace the disabled "View Project" `<span>` with `<a class="button button-primary button-sm" href="YOUR-URL">View Project</a>`.
- GitHub/LinkedIn: change each dashed `<span class="pending-link">` into `<a href="URL" target="_blank" rel="noreferrer">GitHub ↗</a>`.
- Placeholder text styled `.todo` can be un-styled by removing that class once filled.

## Preview / publish
Open `index.html` in a browser. For GitHub Pages, upload the files with `index.html` at the repository root and enable Pages in the repository settings.
